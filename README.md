# Stylez Arcade

The world Callmestylez exists inside. Next.js app router, mock content in `data/`, local save data in `localStorage`.

## Run

```bash
npm install
npm run dev
```

## Where to edit

- Social URLs: `data/socials.ts`
- Releases, lyrics, streaming links: `data/releases.ts`
- Real audio: replace `public/audio/*.wav` and update paths on each release
- Cover art / portraits: `public/art/`
- Player save / achievements: `lib/player-state.ts`, `lib/achievements.ts`
- Future backend: `lib/supabase/` and `lib/content.ts`

## Secrets

Konami (↑ ↑ ↓ ↓ ← → ← →) awards a Stylez Token. Southside has a hidden glint. `/secret` is an unlisted room.
